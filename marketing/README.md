# Launch assets

Print and digital assets for SubSub's growth campaign. Nothing in this folder is
published to subsub.work: the site's `.assetsignore` is an allow-list and
`marketing/` is not on it.

| File | What it is |
|---|---|
| `badge/subsub-verified-color.svg` | The SubSub Verified seal, full color (forest and gold) |
| `badge/subsub-verified-one-color.svg` | One color (forest), on a transparent background |
| `badge/subsub-verified-reversed.svg` | Reversed (white), for dark backgrounds |
| `print/decal-6in.pdf` | Truck decal, 6 in round, with 1/8 in bleed (6.25 in page) |
| `print/decal-6in-art.svg` + `decal-6in-cutline.svg` | The same art as vector, and the die-cut circle on its own |
| `print/sticker-3in.pdf` | Sticker, 3 in round, with 1/8 in bleed (3.25 in page) |
| `print/sticker-3in-art.svg` + `sticker-3in-cutline.svg` | Vector art and cut line |
| `print/flyer-letter.pdf` | Supply-house flyer, US letter, QR code to `subsub.work/subs`, with one line on the $100 for bringing in a GC (terms on `/subs`) |
| `print/flyer-letter-es.pdf` | The same flyer in Spanish. Its QR code adds `utm_content=es`, and it says the terms on `/subs` are in English |
| `copy-pack.md` | SMS scripts, the GC onboarding emails, video hooks and Facebook posts |

## For the print shop

- **Vector, with no live text.** The lettering is outlined from the brand faces
  (Bricolage Grotesque and Inter), so nothing needs a font installed. The flyer
  is a PDF with its fonts embedded.
- **Bleed and cut.** The decal and sticker art extends 1/8 in past the cut. The
  cut is a circle at the finished size; the `-cutline.svg` files carry it alone
  as a 1 pt magenta (#FF00FF) stroke, on the same canvas as the art.
- **Color.** Files are RGB. The brand colors are forest `#103528`, gold
  `#E39B32`, bone `#F4F6F4`, ink `#0C1C16`. Ask the shop to convert to their
  CMYK profile and send a proof. The forest green is the one that shifts.
- **Decal material.** Outdoor vinyl with a UV laminate; the QR code has to stay
  readable after a year in the sun.
- **Flyer.** Letter, no bleed: it is designed to print on an office printer or
  a copy-shop run without trimming.

## Why the decal has a QR code and the sticker does not

"SubSub Verified" on a screen is drawn only while the license checks out and the
insurance is current. On a truck door it would say so for the life of the vinyl,
long after either lapses. So the decal does not rest on the claim alone: its
center is a QR code under **SCAN TO CHECK**, pointing at a live check
(`subsub.work/check/` by default). A customer who wants to know can know today.

The 3 in sticker has no room for a code that scans from across a driveway, so it
is the seal alone. **Hand stickers only to subs whose badge is live**, and treat
them as a thank-you rather than a credential.

When each sub has a page of their own, print a decal that points at it:

```
cd app && npm run assets -- --url https://subsub.work/...
```

## Rebuilding

Everything here is generated by `app/scripts/build-assets.mjs`; edit that, not
the files.

```
cd app && npm run assets
```

The lettering is read from `build/glyphs.json`, which is committed, so the
badges and print art rebuild with nothing else installed. Re-outlining the
lettering (a new word on the seal) or rebuilding the flyer needs the font files,
which are not committed:

```
marketing/build/fetch-fonts.sh        # Bricolage Grotesque + Inter, SIL OFL, from Google Fonts
pip install fonttools
python3 marketing/build/glyphs.py     # rewrites build/glyphs.json
```

The flyer build refuses to write a PDF that runs past one page or into its own
footer.
